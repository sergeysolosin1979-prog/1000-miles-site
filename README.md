# 1000 Miles website

Public informational website for the Android app 1000 Miles.

- Home: https://sergeysolosin1979-prog.github.io/1000-miles-site/
- Privacy: https://sergeysolosin1979-prog.github.io/1000-miles-site/privacy.html
- Support: https://sergeysolosin1979-prog.github.io/1000-miles-site/support.html

## Development

Plain HTML, CSS, and SVG; no dependencies, build step, external fonts, analytics, or client scripts. Serve this directory with any static HTTP server, for example `python -m http.server 8765`, and open http://localhost:8765.

GitHub Pages publishes the root of the `main` branch. `.nojekyll` ensures files are served directly. Support uses this repository's public Issues.

## Content and assets

The approved launcher icon is the only asset copied from the Android project. The landscape SVG was created specifically for this website. Android source, signing material, credentials, and app build outputs do not belong in this repository.

The privacy policy describes the current on-device storage, user-selected JSON import/export, absence of app networking/accounts/ads/analytics, and separate GitHub hosting and public support. Review it when app data handling changes.
